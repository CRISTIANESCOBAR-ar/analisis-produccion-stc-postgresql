DashboardMezclaHilo - Datos que se pasan al analizador local
Fecha de referencia: 2026-03-15

============================================================
1) FLUJO DE ENVIO (Informe IA local y fallback)
============================================================

Frontend (DashboardMezclaHilo.vue) envia a POST /api/dashboard/narrativa-lotes:

body JSON:
- rows: array con comparativa HVI + Uster + Tensorapid por lote
- proveedores: array con resumen HVI por proveedor del lote
- loteActual: numero de lote actual
- fechaCorte: string YYYY-MM-DD
- modo: "local" (solo cuando se fuerza Local desde UI); en Gemini va undefined

Backend (server.js) decide:

A) Modo local directo:
- Se activa si modo === "local" o si no hay GOOGLE_API_KEY.
- Construye datasets adicionales (rowsPorFecha, rowsMaquinas, rowsProduccionOe).
- Llama:
  generarNarrativaLocal(rows, loteActual, proveedores, rowsPorFecha, rowsMaquinas, rowsProduccionOe, fechaCorte)

B) Camino Gemini y fallback local:
- Construye datasets Gemini (rowsPorFechaGemini, rowsMaquinasGemini, rowsProduccionOeGemini).
- Intenta generar con Gemini.
- Si Gemini falla (cuota/red/etc), fallback:
  generarNarrativaLocal(rows, loteActual, proveedores, rowsPorFechaGemini, rowsMaquinasGemini, rowsProduccionOeGemini, fechaCorteGeminiKey)

Nota importante:
- En fallback, fechaCorteGeminiKey puede ajustarse automaticamente a una fecha efectiva disponible.
- El generador local es el mismo en ambos caminos.

============================================================
8) SECCION CARDAS (aun no implementado en analizador local)
============================================================

Estado actual:
- El analizador local NO recibe ni usa cardasContext.
- cardasContext se obtiene en GET /api/dashboard/mezcla-lotes para visualizacion del dashboard,
  pero no se incluye en POST /api/dashboard/narrativa-lotes ni en generarNarrativaLocal(...).

Resumen:
- Cardas esta disponible para UI del dashboard.
- Cardas aun no forma parte del payload del analizador local (ni local directo ni fallback).
